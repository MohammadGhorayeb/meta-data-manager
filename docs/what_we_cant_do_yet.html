What Our Scrubber Can't Do Yet

Our tool removes hidden personal details from files: names, GPS locations, dates, serial numbers. It does that job well. But it cannot do everything, and this page lists what it can't do.

The tool cleans at up to three strengths. The light clean removes the details and changes nothing else. The stronger cleans also rebuild the file so it looks like every other cleaned file, which hides the app that made it. Stronger cleans exist for only seven file types so far: JPEG, PNG, MP3, FLAC, M4A, PDF and Word.

Things no cleaning tool can remove

These traces are part of the picture, the sound or the text. Removing them would damage the file. Every tool in the world has the same problem.

  • Camera noise. Every camera sensor leaves a faint, unique pattern in its photos. An expert can match a photo to the camera that took it.
  • Microphone and room sound. A recording carries the sound of the microphone and the room. The hum of the power grid can even help date it.
  • How a file was compressed. JPEG photos and MP3 songs carry a trace of the app that saved them. Only a stronger clean that re-saves the file removes it, and that costs a little quality.
  • How a PDF was laid out. Where each letter sits on the page shows which program made the PDF. This stays even if the page is turned into a picture.
  • How a program was built. A program's code shows which compiler made it. The code is the program, so it can't change.
  • Text you can read. Words hidden under a black box in a PDF are still there. A name printed on a book's title page stays. We warn you, but we don't edit what you wrote.
  • A cleaned file looks cleaned. Someone can tell a cleaning tool was used. They just can't tell where the file came from.

A cleaned file can still hint at the app that made it

We built the tool against an amateur investigator: someone who compares your file with many others using free tools. Even with every detail removed, the way a file is put together can point to the app that made it. It points to an app, not to you. Files we refuse to clean

When the tool can't clean a file safely, it stops and writes nothing. That is safer than handing back a file that still leaks, but you get no cleaned copy.

  • File types we don't handle yet: OpenDocument files, old Office files (.doc, .xls, .ppt), WAV audio, MKV and AVI videos, and .NET programs.
  • Word documents with tracked changes, comments or something embedded, like a chart's spreadsheet. Of 784 real Word files we tested, 99 were refused (about 1 in 8).
  • Excel workbooks with comments, links to other workbooks, pivot tables, or database connections. A pivot table can keep a full copy of its source data, even data deleted from every sheet. A link to another workbook keeps that file's location and a copy of its cells.
  • PowerPoint presentations with comments, embedded fonts, or a chart whose spreadsheet is stored inside. That spreadsheet is a whole Excel file with its own author. We will clean it with the Excel rules next.
  • Signed or locked files: PDFs and programs signed by their maker, encrypted PDFs, and e-books with copy protection. Changing them breaks the signature, or needs a key we don't have.
  • Videos with subtitles, unless you ask us to drop them. A drone's GPS and a film's subtitles look the same from inside the file.
  • Camera RAW photos from less common makers: Pentax, Leica, Hasselblad and Sigma.
  • Archives we can't fully read: password-protected or very large ZIP files, or ones holding a file type we don't clean. 9 of the 42 archives that come with macOS are refused this way.
  • Rare versions of common formats: TIFF files over 4 GB, macOS's changing wallpapers, streaming-style videos, and unusual MP3, BMP and SVG files.

Things we leave in on purpose

These stay because removing them would break the file or change what it shows. The ones at the top come closest to pointing at a person or a machine.

  • A scrambled block in Nikon RAW photos. Nikon scrambles some colour data with a key made from the camera's serial number. We remove the serial number, but the scrambled block still depends on it.
  • Camera make, model and lens in RAW photos. Photo editors need them to show the right colours. Serial numbers, owner names, dates and GPS are removed.
  • Folder-name length in programs. We wipe a program's debug information but keep its space. The size of that space hints at how long the build folder's name was.
  • Screen or printer size in Word drawings. The drawing is measured in that device's units. It could link two drawings to the same machine.
  • Speaker notes and hidden slides in PowerPoint. They are text the author wrote, so they stay. The report counts them, because people often forget a deck still carries them.
  • The cut-away parts of cropped pictures. Cropping in PowerPoint only hides part of a picture; the whole picture is still in the file. We tell you which slides have one.
  • Hidden sheets, rows and columns in Excel. Formulas may use them, so they stay. The report counts them.
  • Bookmark names and links in Word. A table of contents needs them to work. We list them so you can check them.
  • A few spare bytes in BMP pictures. Some apps read them, so changing them could change the picture. Someone could hide a little data there.
  • The app's name inside some videos. WhatsApp, for example, writes its name into the video data itself. We tell you when we find it.
  • The brightness layer in iPhone photos. It makes the photo look right on HDR screens.
  • Font and colour-profile names in PDFs. They can show "this was made on a Mac", but not who made it.

What cleaning can cost you

The light clean costs almost nothing. The stronger cleans trade something away to hide the app that made the file.

  • Photos and music lose a little quality. A stronger clean re-saves them. Very small files can even get bigger.
  • Clean only once. Running a stronger clean on an already-cleaned file loses quality a second time.
  • PDFs turned into pictures lose their text. You can no longer search, copy or use a screen reader. And it still doesn't hide the app.
  • PDFs get bigger. About a third bigger with the deep clean, and many times bigger when turned into pictures.
  • The PDF deep clean needs a second program. Before it writes anything, a separate PDF reader (poppler) checks that every word reads the same and sits in the same place. Without that reader installed, the file is refused.
  • Word's stronger cleans accept all tracked changes and delete comments. The review history is gone. The strongest one may also shift fonts and spacing, and we can't measure how much yet, because our tests don't drive Word.
  • Protected Excel sheets lose their password. The lock stays, but anyone can now remove it. The password itself was stored as a scrambled code, which is a credential.
  • iPhone photos lose their depth maps. Portrait lighting and background effects stop working.
  • Videos lose their timecode and 360-degree motion data. Editing apps can no longer line clips up by time.
  • Big videos need a lot of memory. A 4 GB video needs about 10 GB free. The tool checks first and tells you.
  • The report shows what it removed. Your name or GPS location appears on screen. You can turn the report off.
  • On a Mac, the system tags every new file. The tag sits beside the file, not inside it, and travels only between Macs.

Things we have not tested yet

We don't claim anything we haven't checked. These are open questions, not known leaks.

  • Damaged Word files. Excel and PowerPoint now refuse a file with a part they can't read. Word doesn't yet: 5 of 946 real Word files would change, so we are checking that first.
  • A letter moved inside a word in a PDF. On 30 October we found the PDF deep clean moving letters in files printed from Chrome, while our own check said all was well. It is fixed, and a separate program now checks where every word sits. That program looks at whole words, so a letter moved inside a word is caught only by our own check.
  • Smarter attacks on MP3 audio. We tested one kind of sound analysis. Research describes a deeper kind we haven't tried.
  • Telling Apple's and other apps' M4A audio apart. Even uncleaned files were too alike to test this.
  • How Word documents look in Word after the strongest clean. Our tests don't drive Word yet.
  • Videos from phones and apps. We compared videos from desktop programs only. Real DJI drone and Android clips are not tested yet.
  • Whether a RAW photo points to one exact camera. That needs photos from two cameras of the same model, which we don't have.
  • More than a few RAW photos per maker. We checked about one real file for each format.
  • Drawings inside Word (EMF, WMF). Comparing apps needs Microsoft Office, which our tests don't drive yet.
  • Embedded fonts in Word and e-books from stores. We had no samples.
  • A blind test by someone else. A second person hasn't tried to break the tool yet.

Every point on this page was measured, not assumed. The full technical list, with the numbers behind each point, is the project's limits file (80 entries).
