Where we stand today

Every build phase is finished: the testing foundation, images, audio, documents, camera and video files, program files, and the remaining image types, archives and e-books. A whole folder can be cleaned in one command. Every result is still backed by an automated test, and the tests now run on Linux and on a Mac after every change.

Against the September plan

30 Sep Media formats

iPhone photos finished, video added

  • iPhone photos finished on 18 September, with published results.
  • Video, including the MOV format every iPhone records. iPhone videos hide a second copy of the exact location, which ExifTool leaves and MAT2 cannot open, so the video data is rebuilt instead of copied. That finding cost four days.
  • Camera RAW survey of eight formats from seven camera makers, done before any code was written.
Done · video four days late
31 Oct Feature complete

Every format in, and the tool usable in bulk

  • Camera RAW for all eight formats. Serial numbers, owner names, dates and location are removed, including the copies inside the preview images, and the photo decodes exactly as before.
  • Program files for Linux, Mac and Windows. Build folders, user names in paths and build times are removed, and real programs were checked to run exactly the same afterwards.
  • Archives and the remaining image types: ZIP, EPUB, TIFF, WebP, SVG and GIF. The same folder zipped by four different programs now comes out as one identical file.
  • Bulk use. A whole folder in one command, with one results sheet.
On track · 17 file types
Added not in the plan

Real-world checks, and two more formats

  • Tested on files we did not make: up to 150 per type from macOS and its apps, GoPro's sample videos, three independent readers, and 21,000 deliberately damaged files. Four real defects were found and fixed, among them iPhone photos losing their transparency.
  • Word documents as Word writes them, measured on 784 real files from two public test collections: 678 cleaned, 106 refused with a reason, none crashed. This added the two Windows drawing formats Word embeds (EMF and WMF).
  • BMP pictures, the last picture type the real-file check found refused. MAT2 calls BMP harmless and passes it through unchanged.

Release candidate

Limits still open

There are still some limits we are working to solve, such as a few file types that can still hint at which program made them, and very large files. Each one is written down as soon as it is found, so the tool never claims more than has been tested.
