# Word-authored DOCX samples — local only, never committed

The producer that matters most in Phase 3 is the one that cannot be scripted.
**Microsoft Word** writes the RSIDs, `w14:paraId`/`w14:textId`, `w15:docId`,
`docProps/app.xml` statistics and the `Normal.dotm` template reference that the
OOXML work items are aimed at. It has no CLI on any platform, so unlike every other
producer in this project its files cannot be generated by a test — they can only be
*saved by a human* and then read.

## Why nothing here is committed

These files carry real personal metadata (an author name, a company, an editing
history), which is exactly what makes them useful and exactly why they must not enter
git. `tests/corpus/**/*.docx` is git-ignored; only this README is tracked. That is the
same rule the `tests/corpus/e3/` JPEG peer corpus follows.

## How to populate it

Save two or three short documents from Word into this directory. To keep them useful
without leaking anything you mind:

1. Author them under a **neutral Word profile name**, not your own, if you would
   rather the corpus not carry it — the fields are the subject of the experiment, so
   they must be *present*, but their contents can be anything.
2. Make at least one document with **several editing sessions** (open, type, save,
   close, reopen, edit, save). RSIDs only multiply across sessions, and a
   single-session file understates the leak.
3. Make one with a **comment and a tracked change**, which brings in
   `word/people.xml`, `commentsExtended.xml` and author names.
4. Make one containing **a photo**, which brings in `word/media/` and the recursion
   into the Phase 1 image handlers.

## How the tests find them

`tests/scrub/docx_corpus.py` reads this directory by default, or
`$DOCX_WORD_SAMPLES` if set. When it is empty, `msword` is reported as an **absent
producer** and every result that needed it says *not measured* — never *clean*. That
is the limit-#12 precedent, where Apple's AAC encoder is measured locally and
reported as not automated rather than dropped to keep CI green.
